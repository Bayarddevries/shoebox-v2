Shoebox — Submitter Intake & Crowdsourced Metadata

Event scan → private claim link → submitter provides metadata → admin review → archive (Lightroom)

The join key

  • • Citizen fills consent form → that's their record
  • • Scans saved to a drop-zone folder per submitter (e.g. Dumas-M/)
  • • One consent = one submission = one private link
  • • You never hand-match files

Caption review before Lightroom

  • • Submitter text = proposed, never final
  • • You edit captions in the Contributions tab
  • • Only approved + edited text exports to Lightroom
  • • App shows approved text immediately

Private by capability

  • • 16+ char random token per submission
  • • Link shows ONLY that submitter's photos
  • • Token gates writes; photos are public anyway
  • • No login, no password to reset

Your 8 steps as archive administrator

1
At the event: citizen fills out the consent form (name + contact). Scan their images. Hand originals back. The consent form is their record — no bag ID (that's the CCAP system).
2
On the PC after the event: save each citizen's scans into a drop-zone folder per submitter:
archive/scans/2026-08-29-rm/Dumas-M/ … (or prefix filenames Dumas-M_01.jpg)
3
Process in Lightroom: add/fix captions, titles, people, location, GPS. Export to the photos folder, then run the manifest generator: node scripts/generate_manifest.js. Photos now have ids.
4
Link photos to the submitter: in the Admin Panel → Submissions, open the submission, click [Link Photos]. The tool reads the submitter's drop-zone folder and shows "Dumas-M — 12 photos matched". Confirm.
5
Generate the link: click [Generate Link], copy the URL …/shoebox-v2/?claim=<token>, paste into an MMF Outlook email, send. That's the whole send step.
6
Submitter fills the details: they open the link, see only their photos, and fill people (left→right), location, date, occasion, and the story. Phone-only submitters: call them and enter it for them — same result.
7
Review (your gate): in the Contributions tab, read each proposed caption, edit it to archival standard, approve or decline. Approved = app shows it; approved = eligible for Lightroom.
8
Write back to Lightroom: run the export (admin button or scripts/export_lightroom.js) → CSV/JSON → import into Lightroom. The archive's source of truth now carries the reviewed community metadata. Repeat per event.
